# Kávézóban és étteremben

Az első valódi párbeszéd, amit egy francia utazáson le kell folytatni: asztalt kérni, rendelni, fizetni. Nyelvtanilag három eszközre épül: a feltételes udvariassági formára (*je voudrais*), a partitív névelőre és a *pour moi* típusú rövid válaszokra.

## Tartalom

### Belépés és asztal

- *Bonjour ! Une table pour deux, s'il vous plaît.* — Egy asztalt két főre.
- *Vous avez réservé ?* — *Oui, au nom de …* / *Non.* — Foglaltak? — Igen, … néven.
- *En terrasse ou à l'intérieur ?* — Kint a teraszon vagy bent?

### Rendelés

- ***Je voudrais*** *un café, s'il vous plaît.* — Szeretnék egy kávét. (a *vouloir* feltételes módja: udvariasabb, mint a *je veux*)
- ***Je vais prendre*** *le plat du jour.* — A napi menüt kérem. (futur proche)
- ***Pour moi***, *une salade. **Et pour elle / lui**, …* — Nekem egy saláta. Neki pedig …
- *Qu'est-ce que vous nous conseillez ?* — Mit ajánl?
- *L'addition, s'il vous plaît.* — A számlát, legyen szíves.
- *On peut payer par carte ?* — Lehet kártyával fizetni?

A pincér kérdései: *Vous avez choisi ?* (Választottak?), *Et comme boisson ?* (És inni?), *Ce sera tout ?* (Ennyi lesz?), *Sur place ou à emporter ?* (Itt fogyasztja vagy elviszi?)

### Mennyiség: a partitív névelő

- *Je voudrais **de l'**eau.* — Vizet kérnék.
- *On prend **du** vin rouge.* — Vörösbort kérünk.
- *Une carafe d'eau, s'il vous plaît.* — Egy kancsó (ingyenes csap)vizet. Ez Franciaországban mindenhol kérhető.
- de: *Je n'aime pas **le** fromage* (általános ízlés → határozott névelő).

### Kávézói szótár

| | |
|---|---|
| *un café* | eszpresszó |
| *un café crème / un crème* | tejes kávé |
| *un thé*, *un chocolat chaud* | tea, forró csoki |
| *un verre de vin (rouge, blanc, rosé)* | egy pohár bor |
| *une pression / un demi* | csapolt sör |
| *un croissant*, *un pain au chocolat* | |
| *l'entrée*, *le plat*, *le dessert* | előétel, főétel, desszert (az *entrée* nem főétel!) |
| *la carte* | az étlap |
| *le menu* | a fix árú, többfogásos menü |

### Gyakorlás párban

Otthon: az egyik fél pincér, a másik vendég, egy valódi (online elérhető) francia étlapból. Aztán csere. Ha van rá mód, rendeljetek egy budapesti francia pékségben franciául.
